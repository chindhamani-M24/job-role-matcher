# 💼 Interactive Job Role Matcher

A simple Python and Machine Learning project that analyzes a candidate's professional background, skill set, or project summary in real-time and predicts the best-matching job role.

---

## 🚀 Features
* **Role Classification:** Uses TF-IDF vectorization and Logistic Regression (`scikit-learn`).
* **Real-time Analysis:** Instantly matches keywords to the most relevant professional career path.
* **Interactive Terminal Loop:** Test custom background descriptions live.

---

## 🛠️ Tech Stack
* Python 3.x
* Pandas
* Scikit-Learn
